# Atividade F056 - Classes em C++ para Objetos Físicos

## Exercício 1: Energia Transversa Faltante (SimpleMET)

Este exercício implementa a classe `SimpleMET` para calcular o vetor de energia transversa faltante através da soma vetorial de objetos reconstruídos.

### Como compilar e testar
Navegue até a pasta do exercício, utilize o `make` para gerar a biblioteca compartilhada e compilar o código, e então execute o programa de teste:

```bash
cd ex1_met
make
./testMET
